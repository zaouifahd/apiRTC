# SEO national et collecte de données

## Stratégie SEO nationale

Créer des pages indexables par combinaison :

- Catégorie + ville : `/oran/restaurants`, `/alger/plombiers`.
- Catégorie + wilaya : `/wilaya/bejaia/hotels`.
- Intention longue traîne : `restaurant romantique oran vue mer`.
- Fiches lieux : nom, adresse, horaires, téléphone, avis, FAQ IA.

Chaque page doit inclure titre local, description, données structurées Schema.org, FAQ, liens internes vers catégories voisines et contenu unique généré à partir de données vérifiées.

## Collecte de données

1. **OpenStreetMap** : importer POI publics avec attribution, catégorie, coordonnées et tags.
2. **Imports CSV contrôlés** : listes partenaires, chambres de commerce, offices de tourisme.
3. **Contribution utilisateurs** : ajout de lieux, correction d'horaires, photos, avis.
4. **Revendiquer une fiche** : professionnels et commerces peuvent prouver la propriété.
5. **Campagnes locales** : ambassadeurs par ville pour enrichir les données critiques.
6. **Modération IA + humaine** : doublons, coordonnées incohérentes, faux avis, spam.

## Qualité des données

- Score de complétude par fiche.
- Historique de modifications.
- Validation téléphone et identité pour modifications sensibles.
- Déduplication par nom, distance, téléphone et similarité sémantique.
