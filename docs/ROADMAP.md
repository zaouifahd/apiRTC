# Roadmap AFRITE

## Plan de développement en 12 phases

1. **Fondation produit** : identité, landing page, design system, catégories algériennes.
2. **Base technique** : Next.js, Prisma, PostgreSQL, Auth.js, Docker local.
3. **Explore V1** : CRUD lieux, catégories, photos, horaires, téléphone, carte.
4. **Avis V1** : notes, commentaires, agrégats, modération simple.
5. **Profils utilisateurs** : compte, téléphone, ville, wilaya, image, préférences.
6. **Score Afrite** : réputation, badges, vérification progressive.
7. **Demandes V1** : publication de besoin, propositions, statut, budget.
8. **Messagerie** : conversations liées aux demandes, notifications email/SMS.
9. **Recherche Meilisearch** : index lieux, professionnels, demandes, filtres géographiques.
10. **AFRITE AI V1** : intention, recherche conversationnelle, résumé d'avis.
11. **Data acquisition** : import OpenStreetMap, revendication de fiches, portail pro.
12. **Monétisation** : Afrite Pro, visibilité prioritaire, publicité locale, commissions.

## V1 — plateforme utilisable

- Explore public avec SEO par ville, wilaya et catégorie.
- Avis et résumé IA.
- Comptes utilisateurs, badges de base et Score Afrite.
- Demandes ouvertes avec propositions.
- Recherche conversationnelle simple.

## V2 — marketplace locale

- Profils professionnels complets.
- Paiement/commission selon disponibilité réglementaire.
- Messagerie temps réel.
- Matching avancé et alertes.
- Tableau de bord Afrite Pro.

## V3 — OS local intelligent

- Planificateur de journée.
- Recommandations personnalisées.
- Détection avancée des faux avis.
- Assistant commercial IA pour professionnels.
- Expansion villes, API partenaires et analytics nationaux.
